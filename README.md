# Qimen — тестовый калькулятор Ци Мэнь

Браузерный калькулятор часовой карты Ци Мэнь Дунь Цзя. Сервер для расчёта не нужен: движок запускается локально в браузере, а GitHub Pages раздаёт статические файлы.

## Что работает в v0.4

- тестовый диапазон: 31.08–06.09.2026, Сочи;
- все двухчасовки;
- единый час Крысы 23:00–01:00 с отнесением к следующему расчётному дню;
- отдельные методы Чай-Бу `拆補法` и Чжи Жунь `置闰法`;
- земная и небесная тарелки, девять звёзд, восемь врат, восемь духов;
- Чжи Фу, Чжи Ши, Сюнь-шоу, скрытый Цзя, точки дня и часа;
- переключатель истинного солнечного времени для Сочи;
- Фу Инь / Фань Инь;
- устойчивый номер часовой карты 1–1080: 18 блоков «тип Дунь + цзюй» по 60 часов Цзя-цзы;
- часовая пустота и скаковая Лошадь, вычисляемые движком;
- пять слотов методов в реестре, из которых третий–пятый пока скрыты.
- классические иероглифы с цветами пяти стихий, рамки Чжи Фу и Чжи Ши, затемнение пустого дворца и значок Лошади;
- общий переворот всей карты и независимый переворот каждого дворца строго вокруг его центральной оси;
- русская и английская расшифровка на оборотной стороне с расширяемым местом под будущие сведения;
- светлая и тёмная темы, три размера символов, легенда и полноэкранный режим;
- стрелки часа и дня внутри тестовой недели, а также подготовленные отдельные модули дня, месяца и года.

За пределами тестовой недели программа останавливает расчёт с понятным сообщением. Полный диапазон 1000–2500 будет подключаться после сверки тестовой версии с эталонными картами.

## Архитектура

| Слой | Каталог | Назначение |
|---|---|---|
| Календарь | `src/calendar` | столпы тестовой недели |
| Время | `src/time` | города, часовые пояса, солнечная поправка и двухчасовки |
| Методы | `src/methods` | независимые правила Чай-Бу и Чжи Жунь |
| Движок | `src/engine` | тарелки, звёзды, врата, духи и итоговый объект карты |
| Типы карт | `src/chart-types` | независимые часовой, дневной, месячный и годовой модули |
| Языки | `src/i18n` | реестр переводов; сейчас RU/EN, новые языки подключаются отдельным файлом |
| Интерфейс | `src/interface` | только чтение результата и отрисовка сетки |

Благодаря этому дизайн можно менять, не переписывая расчёт, новые методы добавляются через `src/methods/registry.js`, а новые языки — через `src/i18n`.

Дневной, месячный и годовой переключатели намеренно недоступны до методической проверки соответствующих алгоритмов: интерфейс и модульные точки расширения уже готовы, но часовая карта не выдаётся под видом другого типа расчёта.

## Проверка

```bash
npm test
npm run build
```

Автотесты фиксируют контрольные карты 02.09.2026 для часов Кролика, Собаки и Свиньи, нумерацию 1–1080, пустоту, Лошадь, переход юаней Чай-Бу, отдельный результат Чжи Жунь и правило часа Крысы.

## Методическая база

Таблицы исходных дворцов и рядов цзюй сверяются с классической схемой, опубликованной в [奇門遁甲統宗](https://zh.wikisource.org/wiki/%E5%A5%87%E9%96%80%E9%81%81%E7%94%B2%E7%B5%B1%E5%AE%97). Алгоритм Чжи Жунь реализован независимо и дополнительно сопоставлен с открытым проектом [qmenpowers](https://github.com/skyfiredao/qmenpowers). Перед расширением диапазона каждая пограничная дата должна быть проверена по эталонному калькулятору.
