# Калькулятор Ци Мэнь — Чай-Бу

Прототип веб-калькулятора часовой карты Ци Мэнь Дунь Цзя по методу Чай-Бу (拆補法).

## Что уже работает

- визуальная сетка 9 дворцов в раскладке Лошу;
- два контрольных расчёта: Сочи, 02.09.2026, часы Собаки и Свиньи;
- четыре столпа, Инь/Ян Дунь, номер цзюй, Сюнь-шоу, Чжи Фу и Чжи Ши;
- подсветка дня и часа по небесной тарелке;
- пошаговая цепочка расчёта;
- адаптация под телефон и компьютер;
- расчёт и отрисовка полностью в браузере, без сервера.

## Ограничение версии 0.1

Это проверочный прототип на подтверждённых контрольных картах. Полный календарный и расчётный движок для произвольной даты будет подключён следующим этапом.

## Локальный запуск

Откройте `index.html` в браузере. Дополнительные зависимости и сервер не нужны.
